**重点复盘 — Hankson趣味题**：

```cpp
// 核心条件：
// 1. gcd(x, a0) = a1
// 2. lcm(x, b0) = b1  →  x / gcd(x, b0) * b0 = b1
//
// 优化：只枚举 b1 的约数（O(√b1)），而非暴力枚举所有数
for (int i = 1; i <= sqrt(b1); i++) {
    if (b1 % i == 0) {
        // 检查 i 和 b1/i 两个约数
    }
}
```

**重点复盘 — 质因数分解+独立性**：  
此题考察了"每个质因子独立"的思想。将 `t = y/x` 分解质因数后，每个质因子指数 `k` 的分配方案数为 `f(k) = (k+1)^n - 2·k^n + (k-1)^n`（容斥原理去掉两端极值情况），最终答案是所有质因子方案数的乘积。

### 2.3 二分查找 & 二分答案（约5题）

| 题目 | 类型 | 核心技巧 |
|------|------|----------|
| 二分法求函数的零点 | 浮点二分 | `eps = 1e-7`，`fabs(f) <= 1e-6` 判零点 |
| 查找最接近的元素 | 整数二分 | 二分后比较 `arr[r]` 和 `arr[l]` 谁更接近 |

| **111.cpp（借教室-优化版）** | 二分答案 + 差分数组 | 二分"前mid个订单是否可行"，差分 O(1) 区间加 |
| **2222.cpp（数列分段）** | 二分答案 + 贪心验证 | 猜"最大段和上限"，贪心分段数是否 ≤ m |

**重点复盘 — 借教室（二分+差分）**：

这是集训中一道重要的"二分答案"应用题。暴力版（`D - 借教室.cpp`）每次订单都直接循环扣减，复杂度 O(nm)，只能过小数据。优化版（`111.cpp`）用二分答案 + 差分数组：

```
二分逻辑：
  check(mid)：前 mid 个订单的区间加法是否导致某天教室为负？
    → 差分数组 diff[s[i]] += d[i], diff[t[i]+1] -= d[i]
    → 前缀和还原，判断是否超过 arr[i]

二分边界：
  l = 1, r = m
  若 check(mid) 为 true  → 前 mid 个订单可行，l = mid + 1
  若 check(mid) 为 false → 不可行，r = mid - 1
```

**重点复盘 — 数列分段**：

"使得每段和的最大值最小"是经典的**二分答案+贪心验证**模型。`check(x)` 贪心地每当累加和超过 `x` 就新起一段，最后看段数是否 ≤ m。

**重点复盘 — 跳房子（a.cpp）**：

这是集训中 DP 难度最高的一道题。`f[i] = max{f[j]} + a[i]`，其中 `j ∈ [i-R, i-L]`。关键是维护滑动窗口最大值：

```cpp
// 双堆惰性删除 (Lazy Deletion) 技巧：
priority_queue<int> q1, q2;  // q1=主堆, q2=待删除堆

// 加入新候选
q1.push(f[i-L]);

// 过期标记
if (i - R - 1 >= L) q2.push(f[i-R-1]);

// 惰性删除：堆顶相同时一起弹出
while (!q2.empty() && q1.top() == q2.top()) {
    q1.pop(); q2.pop();
}

f[i] = q1.top() + a[i];  // q1.top() = 窗口最大值
```

这个技巧在不支持任意删除的 `std::priority_queue` 上实现了 O(log n) 的窗口最大值维护。

**重点复盘 — p1874（字符串分割）**：

```cpp
// dp[i][k] = 前 i 个字符组成和为 k 的最少段数
// 转移：dp[i][k] = min(dp[i][k], dp[j][k - val] + 1)
//       其中 val = num[j+1][i]（子串对应的数值）
//
// 关键优化：当 val > n 时直接 break（剪枝）
```

## 四、主要收获

### 4.1 方法论层面的提升

1. **二分答案的建模能力**：从"借教室"和"数列分段"两题，掌握了 `check(mid)` 验证 + 二分边界调整的标准套路。这是 OI 中最常用的"化判定为优化"技巧。

2. **差分数组优化区间操作**：`111.cpp` vs `D - 借教室.cpp` 完美展示了"暴力区间修改"到"差分 O(1) 区间修改"的性能飞跃。

3. **惰性删除（Lazy Deletion）**：`a.cpp`（跳房子）引入的双堆技巧，是对 STL 限制的巧妙绕过。

4. **质因数独立性的计数思想**：质因数分解题中"每个质因子独立计算，方案数相乘"的思路是组合数学的核心。

### 4.2 代码习惯的提升

- 整理了完整的高精度模板和比赛模板
- 开始使用 `typedef long long ll`、`ios::sync_with_stdio(false)` 等优化
- 二分边界处理更加熟练（`l <= r` vs `l < r`，`ans` 变量的角色）

### 4.3 还存在的不足

1. **图论题做得太少**：除了建图模板，没有真正用 Dijkstra / 并查集 / 拓扑排序解题
2. **DP 状态设计不够熟练**：跳房子和字符串分割两题的 DP 设计较慢
3. **二分无向图染色判断**：文件是空的，说明这道题还没开始写
4. **L.cpp 中 `ios_base` 写错**：应该是 `ios::sync_with_stdio`，不是 `ios_base`
5. **`计算2的N次方.cpp` 实际写的是阶乘**：文件名和内容不匹配
6. **M.cpp 中的变量名 `c` 冲突**：局部数组 `c` 和 `c` 变量重名
